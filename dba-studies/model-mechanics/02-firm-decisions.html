2. Firm expectations and decisions

Each firm converts expected growth, inflation, current demand, and production constraints into next-period targets.

InputsDemand, prices, stocks, productivity, expectations
MechanismScale demand → price costs → resource targets → finance gap
OutputsDesired output, inputs, jobs, credit, price
1. Set desired output and price

Expected growth scales current demand. Price combines expected inflation with cost pressure from labour, materials, and capital.

Qˢᵢ = Qᵈᵢ(1+γₑ)Pᵢ′ = Pᵢ(1+πᶜᵢ)(1+πₑ)

Cost pressure compares each input price with the firm’s current output price, weighted by technical coefficients.

2. Translate output into resource targets

Capital limits attainable output first. Depreciation determines desired investment, intermediate productivity determines material demand, and labour productivity determines desired headcount.

Iᵈᵢ = (δᵢ/κᵢ)·min(Qˢᵢ, Kᵢκᵢ)DMᵈᵢ = min(Qˢᵢ, Kᵢκᵢ)/βᵢNᵈᵢ = max(1, round(min(Qˢᵢ,Kᵢκᵢ)/ᾱᵢ))
3. Forecast profits and balance sheet

Past profit grows with expected prices and output. Expected deposits subtract repayment, corporate tax, and dividends. Capital is revalued and old loans amortize.

Πᵉᵢ = Πᵢ(1+πₑ)(1+γₑ)ΔDᵉᵢ = Πᵉᵢ − θLᵢ − τFIRM·max(0,Πᵉᵢ) − θDIV(1−τFIRM)·max(0,Πᵉᵢ)
4. Request only the funding gap

A firm asks for credit only when expected cash flow plus existing deposits is negative.

DLᵈᵢ = max(0, −ΔDᵉᵢ − Dᵢ)
