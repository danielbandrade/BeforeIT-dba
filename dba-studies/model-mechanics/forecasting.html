GDP and inflation forecasting

estimate_next_value re-estimates a stochastic AR(1) model from all observations available at the current simulation period.

1. The forecasting model

The regression estimates persistence α, intercept β, and residual variance. A new residual shock is drawn for the forecast.

\[x_{t+1} = \alpha x_t + \beta + \varepsilon_{t+1}\] \[\varepsilon_{t+1} \sim \mathcal{N}(0,\hat{\sigma}^{2})\]

The Julia implementation is equivalent to:

```julia
alpha, beta, epsilon = estimate(data)
forecast = alpha * data[end] + beta + epsilon
```
2. GDP forecast

The AR(1) model operates on log GDP. Exponentiation converts the result back to GDP units; expected growth compares it with current GDP.

\[\log(Y_{t+1}^{e}) = \alpha_Y\log(Y_t) + \beta_Y + \varepsilon_Y\] \[Y_{t+1}^{e} = \exp\!\left(\alpha_Y\log(Y_t)+\beta_Y+\varepsilon_Y\right)\] \[\gamma_{t+1}^{e} = \frac{Y_{t+1}^{e}}{Y_t}-1\]
3. Inflation forecast

agg.pi_ stores log price changes. The forecast becomes an ordinary percentage rate through exp(...) - 1.

\[\ell_{\pi,t+1}^{e} = \alpha_\pi\ell_{\pi,t} + \beta_\pi + \varepsilon_\pi\] \[\pi_{t+1}^{e} = \exp\!\left(\ell_{\pi,t+1}^{e}\right)-1\]
4. Try one GDP forecast

This calculator accepts fitted values directly. In the model, rfvar3 estimates α and β, while ε is drawn using the estimated residual deviation.

5. Why forecasts vary between runs

Each call draws a new ε. Set Julia’s random seed before constructing and running the model when reproducibility is required.

```julia
using Random
Random.seed!(123)
```
